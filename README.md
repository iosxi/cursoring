# cursoring

LittleBigMouse の「モニタの物理サイズと配置に合わせてカーソル移動を補正する」機能だけを
C (Win32 API) で実装した軽量な常駐ソフトです。

- インストール不要。`cursoring.exe` 単体で動作 (VC ランタイムも静的リンク)
- レジストリへの書き込みなし。設定は exe と同じフォルダの `cursoring.ini`
  (モニタの EDID を読むためにレジストリを**読み取り**のみ行います)
- 常駐時のメモリ: プライベート約 1.5MB

## 使い方

1. `cursoring.exe` を好きなフォルダに置いて起動するとタスクトレイに常駐します。
   初回起動時にモニタの物理サイズ (EDID) と Windows の配置から `cursoring.ini` を作ります。
2. トレイアイコンをダブルクリック (または右クリック →「レイアウト設定」) で設定画面を開き、
   モニタの四角を**実際の机の上の配置どおり**にドラッグして「保存」します。
   - 辺は近くのモニタの辺に吸着します。数値 (mm) で指定することもできます。
   - 赤い点は現在のカーソル位置です。実際にマウスを動かして境界の高さが合っているか確認できます。
3. 右クリックメニューで補正の有効/無効を切り替えられます。

exe をもう一度起動すると、常駐中のインスタンスの設定画面が開きます。

### スタートアップ登録 (レジストリを使わない方法)

`Win + R` → `shell:startup` で開くフォルダに `cursoring.exe` のショートカットを置いてください。

## 補正の仕組み

低レベルマウスフックで「カーソルが今のモニタの外へ出ようとした瞬間」を捉え、
はみ出した位置を今のモニタの縮尺で物理座標 (mm) に換算し、その位置にあるモニタの
対応するピクセルへカーソルを置きます。物理的に続きのない方向へは出さず、端で止めます。

このため Windows の「ディスプレイ設定」上ではつながっていない位置からでも、
物理的に隣接していればモニタ間を移動できます。

## cursoring.ini

```ini
[General]
Enabled=1          ; 1=補正する
JumpGaps=1         ; 1=モニタ間に隙間(ベゼル等)があっても、その方向の隣のモニタへ飛び移る
IgnoreInjected=1   ; 1=ソフトウェアが生成したマウス入力(タブレットドライバ等)は補正しない
MaxJumpPx=400      ; 今のモニタからこれより遠くへの移動は絶対座標入力とみなして補正しない (0=無制限)

[Monitor.GSM7707.5&3568f48a&0&UID4353]   ; 機種コード.接続インスタンス
Name=LG HDR 4K         ; 表示用
Resolution=3840x2160   ; 表示用 (読み込みには使いません)
WidthMM=600.00         ; 画面の表示領域の物理サイズ
HeightMM=340.00
X=0.00                 ; 物理位置 (mm)。相対値なので原点はどこでもよい
Y=0.00
```

ini を手で編集した場合は、トレイメニューの「モニタ再検出 / ini 再読み込み」で反映されます。
モニタの接続や解像度変更は自動で検出します。

## 注意

- **ペンタブレット / 液タブ**: ペンやタッチの入力、ドライバが送る入力は補正しないようにしています。
  それでもペン操作が境界付近でずれる場合は `MaxJumpPx` を小さくしてください。
- ゲームなどがカーソルの移動範囲を制限しているときは補正しません。
- 管理者権限で動いているウィンドウの上で補正が効かない場合は、cursoring も管理者として
  実行してみてください (この点は未検証です)。
- EDID の値はパネルによって不正確なことがあります。実測値を設定画面で入力してください。

## ビルド

Visual Studio 2022 Build Tools (MSVC) で:

```bat
build.bat        :: build\cursoring.exe を作成
build.bat test   :: あわせて座標変換の単体テストを実行
```

| ファイル | 内容 |
|---|---|
| `src/main.c` | 常駐・トレイ・マウスフック |
| `src/mapping.c` | ピクセル⇔物理座標の変換と移動先の計算 |
| `src/monitors.c` | モニタ列挙、EDID 読み取り、ini 読み書き |
| `src/editor.c` | レイアウト設定画面 |
| `test/test_mapping.c` | `mapping.c` の単体テスト |
